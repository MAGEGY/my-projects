ARIA Presence (Friends) LIVE

System (web app + API + vector DB on Render) · Friends project - deployed from Render blueprints

Open live site

What it does

  • ARIA is a presence/prompt-sharing system built around a conversational assistant.
  • It has three deployed parts on Render: the web app, a Python presence API, and a Qdrant vector database.
  • The web app is the user-facing interface; the API handles presence and prompts; Qdrant stores embeddings.
  • The services were deployed 25 days ago and stay up on Render.
  • The source lives in the local Friends project (Friends/Friends/aria-presence) with its render.yaml blueprint.

Features

  • Web app (static site on Render)
  • Presence API (Python 3 on Render)
  • Qdrant vector database (Docker on Render)

Tech stack

Render blueprints, Python, Qdrant, Docker
