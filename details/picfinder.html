PicToID (picfinder) NOT-DEPLOYED

API service (Python/FastAPI) · Local picfinder project - blueprint ready, not deployed yet

GitHub repository

What it does

  • PicToID is an image identification service.
  • You upload a picture and the API finds its ID - what the image shows.
  • It is a Python FastAPI service with image processing via Pillow and OpenCV.
  • It can describe images, detect faces, and read EXIF data.
  • A Render blueprint is ready in the repo - the plain picfinder.onrender.com subdomain belongs to someone else, so the deploy will be auto-named picfinder-xxxx.

Features

  • Image upload API (FastAPI + python-multipart)
  • Image description and identification engines
  • Face detection (OpenCV)
  • EXIF metadata reading
  • Temporary public hosting for uploaded images (uguu.se, tmpfiles.org, catbox.moe)
  • Static file serving

Tech stack

Python 3.12, FastAPI, uvicorn, Pillow, OpenCV (headless), httpx, Render blueprint

Notes

To deploy: Render dashboard -> New -> Blueprint -> select the PicToID repo. The service will be auto-named picfinder-xxxx because picfinder.onrender.com is taken.
