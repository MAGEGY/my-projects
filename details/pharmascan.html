Pharma-Scan NOT-DEPLOYED

Full-stack web app (Express + PostgreSQL + Expo static client) · Local Pharma-Scan project - blueprint ready, not deployed yet

GitHub repository

What it does

  • Pharma-Scan is a full pharmacy management system with a real backend.
  • It has user accounts with authentication, an Express API, and a PostgreSQL database via Drizzle ORM.
  • The frontend is an Expo app exported to static files and served by the same server.
  • It includes advanced pharmacy features like backup and sync.
  • A Render blueprint is ready - it needs a PostgreSQL database (Render Postgres or Neon free tier) set as DATABASE_URL.

Features

  • Authentication (JWT, bcrypt)
  • Express REST API with Drizzle ORM
  • PostgreSQL database (postgres.js driver)
  • Expo static client served by the server
  • Advanced features: backup, sync, system management

Tech stack

Node 20, Express, TypeScript, esbuild, Drizzle ORM, PostgreSQL, Expo static export, Render blueprint

Notes

Requires DATABASE_URL pointing to a hosted Postgres (Render Postgres or Neon free tier). Note: pharmascan.onrender.com belongs to a different app (MedPrice.ai) - the deploy will be auto-named pharmascan-xxxx.
